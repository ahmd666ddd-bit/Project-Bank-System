# 🏦 Bank Management System (C++)

A comprehensive console-based Bank Management System built using C++ and Object-Oriented Programming (OOP) principles. The project manages bank operations, client records, and user permissions with local text file storage.

---

## 🚀 What the System Does (English)
* Client Management: Add, edit, delete, search, and display client accounts.
* Transactions: Deposit, withdraw, and view total balances across all accounts.
* User & Permission System: Manage system users and control their access permissions.
* Currency Exchange: Handle currency data and exchange operations.
* Data Persistence: Save and retrieve all project data using local text files.

---

# 🏦 نظام إدارة البنك (بلغة C++)

مشروع كامل لإدارة العمليات المصرفية يعمل عبر واجهة الأوامر (Console)، مبني باستخدام لغة C++ ومفاهيم البرمجة الكائنية (OOP)، مع حفظ كافة البيانات في ملفات نصية.

---

## 🚀 ماذا يفعل المشروع؟ (بالعربية)
* إدارة العملاء: إضافة، تعديل، حذف، بحث، وعرض حسابات العملاء.
* الحركات المالية: إيداع، سحب، وعرض إجمالي الأرصدة.
* إدارة المستخدمين والصلاحيات: التحكم بمستخدمي النظام وتحديد صلاحيات كل مستخدم.
* تحويل العملات: إدارة بيانات العملات وحساب عمليات التجميع والتحويل.
* تخزين البيانات: حفظ واسترجاع كافة البيانات تلقائياً في ملفات نصية.
